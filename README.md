# Wireless guitar system

This repository includes code and documentation of the Wireless guitar system project built using Xiao ESP32-S3 module and WM 8960 codec and programmed in ArduinoIDE.

## Catalogs structure

Esp32s3\_testing and EspWroom32\_testing - contains projects that were used in testing and development of the system

SparkFun\_WM8960\_Arduino\_Library - library used in codec configuration
Wireless\_audio\_transmittion - contains current versions of the projects for the transmitter and the receiver
Docs - contains documentation and other documents
