# Wireless guitar system
This repository includes code and documentation of the Wireless guitar system project built using Xiao ESP32-S3 module and WM 8960 codec and programmed in ArduinoIDE.
## Catalogs structure
Esp32s3_testing and EspWroom32_testing - contains projects that were used in testing and development of the system
Wireless_audio_transmittion - contains current versions of the projects for the transmitter and the receiver
Docs - contains documentation and other documents
